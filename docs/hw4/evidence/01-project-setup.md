## 4. `.claude/settings.json`

Design:

- **allow** — read-only inspection (`Read`, `Glob`, `Grep`, `git status/diff/log/show`) and the project's verification scripts (`test`, `typecheck`, `lint`, `build`) for both the Bash and PowerShell tools, with `npm` and `npm.cmd` spellings.
- **ask** — anything that changes Git state or the dependency tree (`git add/commit/push/checkout/switch/merge/stash/tag`, `npm install/uninstall`), starting the dev server, and `WebFetch`.
- **deny** — history rewriting and destructive commands (`push --force`/`-f`, `reset --hard`, `rebase`, `commit --amend`, `clean`, `filter-branch`, `rm -rf`, `Remove-Item -Recurse`), raw network downloads (`curl`, `wget`), and reading/editing `.env*`, `*.pem`, `*.key`.
- `defaultMode: "default"` so nothing outside the lists is pre-approved.
- `.claude/settings.local.json` stays git-ignored (already in `.gitignore`) for personal overrides.

Note: a session-level permission mode (for example auto mode in the Desktop app) can still decide on prompts for rules in the `ask` list; `deny` rules always apply.

### Validation

The schema at `https://json.schemastore.org/claude-code-settings.json` was downloaded to the session scratchpad. A Node script checked that the file parses, that every key under `permissions` is a known key, that `defaultMode` is in the schema enum, and that every rule matches the schema's `permissionRule` pattern (which lists both `Bash` and `PowerShell` as valid tool names).
